How the import works

  • The file needs a Date column and either an Amount column, or separate Debit and Credit columns.
  • A description column (Description, Narration, Particulars, Details or Remarks) is used to pick the category automatically.
  • With a single Amount column, negative values are treated as expenses and positive values as income. An optional Type or Dr/Cr column overrides this.
  • Dates are read day-first (for example 05/10/2026 is 5 October 2026).
  • Rows already in your account with the same date, amount, description and type are skipped, so importing the same file twice is safe.
