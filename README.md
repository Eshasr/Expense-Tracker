# SmartSpend AI 📊

SmartSpend AI is a full-stack personal finance and expense tracking web application designed to help users monitor daily spending habits, visualize categorical budgets with interactive charts, and seamlessly import bank statement files.

## 🚀 Key Features

- **User Authentication:** Secure user signup, login, and session management powered by Flask-Login with password hashing.
- **Interactive Analytics:** Dynamic data visualizations built with Chart.js to track expense distributions and budget trends.
- **Automated Statement Import:** Backend processing of CSV and Excel financial files using Pandas and Openpyxl.
- **Relational Data Management:** Persistent SQLite database operations handled via Flask-SQLAlchemy (MVC architecture).

## 🛠️ Tech Stack

- **Backend:** Python, Flask, Flask-SQLAlchemy, Flask-Login, Gunicorn
- **Data & Processing:** Pandas, Openpyxl
- **Frontend:** HTML5, CSS3, JavaScript, Chart.js
